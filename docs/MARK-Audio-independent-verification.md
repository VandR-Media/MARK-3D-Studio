# MARK 3D Studio v0.3 — независимая техническая проверка для разработки MARK Audio

Дата: 16 ноября 2026. **Статус: экспериментальная разработка, PR #3, не готовая модель MARK Cosmic.**

Ссылки: репозиторий `VandR-Media/MARK-3D-Studio`, ветка `develop/character-modeling-v0.3`, PR https://github.com/VandR-Media/MARK-3D-Studio/pull/3.

## Предмет проверки

Проверить **настоящий бинарный GLB 2.0**, а не только визуальное изменение Three.js. Последовательность: загрузить голову из `scripts/export-character.mjs` / `src/head-fixture.js` → выбрать полигон → Extrude/Inset/Subdivide → Face Studio (нос, щёки, подбородок) → дублировать отдельный меш с уникальными accessors → назначить новый PBR → экспорт → повторный импорт → сравнить FLOAT32 POSITION, NORMAL, indices, UV, materials, hierarchy.

```bash
npm install --no-audit --no-fund
npm test
```

Для **реального браузерного теста** запустить workflow `.github/workflows/browser-v03.yml`, который использует Chromium/WebGL2 с программным рендерингом SwiftShader и скрипт `scripts/accept-v03.mjs`. Артефакт должен содержать исходный, изменённый, повторно открытый рендеры (спереди/сбоку/3/4), портретный экран и `character-v03-edited-in-browser.glb`. Это не тест на Huawei и не аппаратный GPU-бенчмарк.

## Объективные проверки GLB

1. Разобрать GLB: `asset.version = 2.0`; валидные JSON и BIN chunks.
2. Сопоставить количество треугольников до и после Extrude/InSet/Subdivide; именно индексные массивы изменяются, а не только положение объектов.
3. Сравнить POSITION и NORMAL до и после геометрической деформации, проверить конечность координат и пересчёт accessor min/max.
4. Проверить сохранение UV, исходных материалов и текстур, не связанных с изменяемой геометрией. Для нового объекта проверить разные POSITION/NORMAL/indices accessors, чтобы правка одной копии не влияла на другую.
5. Проверить непрерывность: вырожденные треугольники = 0, неманифолдные рёбра = 0, у изначально замкнутой тестовой головы после операций нет открытых рёбер.
6. Проверить сохранение glTF nodes/mesh hierarchy и нового PBR-материала после повторного чтения.
7. Проверить Undo/Redo Face Studio и отдельную историю топологических операций. Проверить реальный IndexedDB автосейв.
8. Проверить явную блокировку skinning/morph/shared/Draco/Meshopt атрибутов, не поддерживаемых опасными правками.
9. На Huawei проверить работу касаний, orientation/горизонтальный экран, file:// и HTTPS открытие, экспорт через браузер, разрешение сохранения, время обработки 25–50 тыс. треугольников, FPS/нагрев/разряд батареи.

## Чего НЕ следует утверждать

- Тренировочная голова не совпадает с утверждёнными изображениями MARK Cosmic.
- Face Studio — простые локальные геометрические деформации непрерывной поверхности, не профессиональная ретопология лица.
- Quad edge-loop Loop Cut и удаление граней с восстановлением отверстий **пока не реализованы**; UI должен выдавать объяснение запрета.
- Материалы по выделенным полигонам, скульптинг закрытой ротовой полости, воссоздание век/ушей, моделирование полноценной одежды, волос и аксессуаров **не завершены**.
- Создание дополнительных объектов сейчас преимущественно через копирование независимого существующего меша с последующим ручным редактированием.
- Реальная совместимость и 60 FPS на Huawei Pura 80 Ultra **не подтверждены**.
- Никакие утверждённые изображения пользователя не публиковались в репозитории; добавлять их туда автоматически нельзя.
