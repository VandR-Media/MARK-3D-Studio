# MARK Cosmic — проект художественного согласования 3D v1

**Статус:** пользователь утвердил *2D-художественный ориентир* (последний лист персонажа с крупным портретом, видами спереди/сбоку/сзади и мимикой, 16 ноября 2026). **3D-модель ещё НЕ утверждена.**

**Программный проект:** `recipes/mark-cosmic-approved-lookdev-v1.json`  
**Ветка:** `feature/mark-cosmic-approved-lookdev-v1` (основана на v0.4.1).  
**Инструмент:** MARK Modeling API, JSON → GLB → рендеры в настоящем Chromium/WebGL2.

## Утверждённый визуальный ориентир

1. **Лицо:** узнаваемые детские пропорции; тёплая естественная кожа, карие глаза обычного размера, тонкие естественные веки, небольшая мягкая переносица и округлый кончик носа, аккуратная небольшая улыбка, мягкие щёки и спокойный подбородок. Внешность сверять с фотографиями, которые пользователь предоставил в личном чате; никаких предположений об абсолютных измерениях лица.
2. **Волосы:** короткие каштаново-коричневые, без шипов и искусственного «шлема». Часть волос видна под кепкой.
3. **Кепка:** красная, с крупной белой буквой M, тёмным козырьком и голубым контурным акцентом.
4. **Наушники:** крупные чёрно-графитовые с неоновыми кольцами cyan/magenta и M на чашках. Вариант на ушах для нейтральных ракурсов; вариант на шее — будущая отдельная поза аксессуара.
5. **Одежда на будущей полной модели:** тёмно-синий худи с цианово-розовой волной звука и полосами на рукавах, свободные серые карго-брюки, массивные кроссовки с голубой/розовой подсветкой.
6. **Стилистика:** полуреалистичная качественная 3D-анимационная эстетика; не шарообразный, не «кукольно-пластиковый», не взрослый персонаж. Нейтральная поза A/T для будущего риггинга; выразительная улыбающаяся мимика отдельно.
7. **Размеры, указанные на иллюстрации**, являются художественными подписями; рост и масштаб в glTF пока не подтверждены физическими измерениями.

## Границы текущей поставки

**Реально автоматизировано:** генерация непрерывной головы, редактирование отдельных черт лица, коричневые радужки, веки, брови, губы, уши, волосы, кепка, наушники, PBR, контроль целостности GLB, сохранение и семь рендеров.

**Не выполнено:** ручное художественное скульптирование с гарантированным сходством с фотографиями; реалистичные текстуры кожи/волос; полноценные глаза и губы с корректной лицевой топологией; тело, худи, карго, обувь; скелет и анимация. На этом шаге не выдавать экспериментальную голову за «готового Марка».

**Конфиденциальность:** оригинальные фотографии ребёнка и утверждённая картинка остаются в переписке; не коммитить и не прикладывать их к публичным артефактам автоматически. В рецепте только художественные параметры и словесное описание.

## Как получить результат

После запуска GitHub Actions открыть workflow `MARK Modeling API v0.4.1` для SHA этой ветки. Из артефакта `mark-3d-studio-v0.4-modeling-api-glb-reports` взять:
- `mark-cosmic-approved-lookdev-v1/mark-cosmic-approved-lookdev-v1.glb`
- `mark-cosmic-approved-lookdev-v1/recipe.json`
- `mark-cosmic-approved-lookdev-v1/report.json`
- `mark-cosmic-approved-lookdev-v1/renders/01-front.png`, `02-left.png`, `03-right.png`, `04-threequarter-left.png`, `05-threequarter-right.png`, `06-face-close.png`, `07-wireframe.png`.

Нужно показать пользователю **настоящие PNG из GLB рядом с утверждённым художественным листом**, без дорисовывания результатов. HTML автономный, но совместимость физического Huawei ещё не подтверждена.

## Что согласовывать

- Похожи ли основные пропорции лица, разрез и цвет глаз, нос, улыбка и уши?
- Достаточно ли естественно выглядят волосы и черты лица со всех сторон?
- Соответствуют ли формы кепки, M и наушников иллюстрации?
- Допустим ли уровень стилизации для движущегося персонажа плеера?
- **Решение:** 3D принимается отдельно от уже утверждённого 2D-концепта.

Если видимых отличий слишком много, в следующей итерации не ограничиваться сменой чисел в JSON: требуется настоящая художественная переработка поверхности/анатомических деталей, текстуры и последующая ретопология. Не сливать в `main` и не интегрировать в MARK Audio до подтверждения владельцем.
