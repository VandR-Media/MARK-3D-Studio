## 2. File structure: an actual archive, not renamed JSON

```text
MARK-Rig-Experiment.markscene   (ZIP/STORE v3-preview)
  manifest.json                # typed metadata/scene graph/edit overlays
  assets/source.glb            # exact original glTF2+BIN+textures+animations
```

Example manifest structure (illustrative, not a rendered result):

```json
{
  "schema": "mark.professional-scene/3-preview",
  "formatStatus": "EXPERIMENTAL_EDITABLE_SUBSET",
  "schemaVersion": 3,
  "projectId": "mark-rig-experimental",
  "units": "meters",
  "upAxis": "Y",
  "fps": 30,
  "assetManifest": [
    {"uuid":"asset-gltf-source","kind":"source","uri":"assets/source.glb",
     "sha256":"<actual SHA-256 generated by code>","byteLength":14276}
  ],
  "sceneGraph": [
    {"uuid":"gltf-node-0","legacyIndex":0,"displayName":"MARK_Rig_Demonstrator",
     "type":"group","parentUUID":null}
  ],
  "edits": {
    "nodeTransforms":{"1":{"translation":[0.36,0,0]}},
    "materialPbr":{"0":{"roughnessFactor":0.23}},
    "selection":{"clipIndex":2,"timeSeconds":6}
  }
}
```

This is a **preview-only schema** (the formal v3 specification remains unapproved). The user/project file is not allowed to execute code on open. ZIP decompression is deliberately refused: only two expected stored entries, fixed file paths, CRC, manifest/version/hash checks.

## 4. Exact remaining blockers

1. Animated Neon Boy in the owner-approved visual quality, and 70-bone *human* rather than a skinned test quad.
2. Native project authoring of actual mesh vertex/edge/face, UV, weights, bones, morph target keyframes, and NLA.
3. Full numeric glTF semantic fidelity with images/texture samplers, exact animations on external multi-mesh assets, multi-rig and compressed extensions.
4. Transactional editing/undo/redo, atomic filesystem saves, autosave/recovery, asset provenance/licence prompts and the official versioned AI Bridge.
5. Real Huawei WebView/Yandex Browser GPU/heat/frames/quality tests; SwiftShader is not phone hardware.

Next pass must begin with re-reading the owner RFC and reviewing the actual CI report from this pass, then pursue **full scene-core v3/provenance and independent external rig asset**, not simply add more technical badges.
