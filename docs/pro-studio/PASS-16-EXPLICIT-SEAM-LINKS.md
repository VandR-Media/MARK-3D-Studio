# MARK 3D Studio — проход №16: подтверждаемые связи через UV-швы и исходно-стабильные логические ID

**Сверено до прохода:** `MARK_3D_STUDIO_FULL_BLENDER_REPLACEMENT_TZ(1).md` (18.11.2026), разделы 0, 3.2–3.3, 4.1, 5.1–5.2, 7.1, 17.2–17.3, 19.2–19.4, 25.1–25.3, 28, 33; `ИНСТРУКЦИИ-для-разработчика.txt`, разделы 2–4, 6–11. Базовая ветка — `feature/pro-studio-pass15-corner-topology` / PR #25, последний CI предыдущего прохода был successful. `main` не меняется.

## Задача / техническое решение

**Feature ID `MESH-SEAM-LINKS-016`**, P0, экспериментальный ограниченный профиль. Цель — избежать опасного автоматического объединения позиций, которые лишь совпадают в пространстве, но имеют разные UV/нормали, при этом явно сохранять решение пользователя о логическом соответствии.

**Готово:**
- Отдельный `src/pro-studio/mesh-seam-identity.js`. Разрешён только **явный**, проверенный пользователем source-bound link `{meshIndex,primitiveIndex,vertexA,vertexB}` между двумя разными glTF attribute rows с точно совпадающими `POSITION`. Автоматического weld нет.
- Для подтверждения валидируются геометрические индексы, нетронутый индексный профиль, исходные `JOINTS_n` и `WEIGHTS_n`, `POSITION`-морфы, принадлежность хотя бы одному треугольнику. При различающихся skin/morph-streams связь отвергается. Создание non-manifold, conflicting winding или degenerate logical triangle также отклоняется.
- После двух подтверждённых пар на тестовом quad UV seam, связь областей из двух треугольников существует **в отдельном аналитическом логическом графе**. Исходные индексы остаются несвязанными, текстурные координаты, исходный GLB и реальные поверхности не изменяются.
- Логические vertex/edge ID детерминированы от **полного SHA-256 исходного GLB**, индексов mesh/primitive и канонического источникового attribute row. Идентичность сохраняется при обратимом `.markscene` save→close→open, native replay, undo/redo связей. В профиле не обещается стабильность ID после топологического редактирования.
- `edits.meshSeamLinks` сохраняется в строгой канонической форме в существующем верифицированном ZIP `.markscene` v3-preview (без отдельного бинарного ресурса). Привязка валидируется повторно при открытии; неизвестные поля, duplicate links и недопустимый target отвергаются.
- Новые AI Bridge команды: `mesh.linkSeam` и `mesh.unlinkSeam` (write grant, Undo/Redo, ограничение в 64 связи) и **только чтение** `mesh.getLinkedRegion` для диагностики логической связной области. `mesh.getTopology` теперь показывает число подтверждённых связей и bounded-данные ID, когда связи есть.
- GUI: кнопки подтверждения и удаления UV-связи между V1 и V2; подтверждение пользователя перед новой связью, сведения о числе связей в диагностике.
- Безопасность: **все изменяющие форму/индексы операции для данного primitive запрещены, пока там есть связи**, потому что у текущего ядра пока нет доказуемо безопасного remap ID. Для безопасных операций над другим primitive блокировки нет. Отказ не уничтожает предыдущие версии проекта.

## Ограничения и границы корректности

- **Логическая связь не является физическим weld** и пока не делает RegionExtrude сквозь UV seam доступным. Вывод `mesh.getLinkedRegion` — только безопасная аналитическая карта. Покрытие целевого ТЗ §5.1 частичное, не production half-edge/N-gon MeshData.
- «Стабильный ID» относится к неизменному **исходному mesh primitive** и native round-trip. После изменения топологии automatic ID remap пока не реализован — поэтому такая операция **не выполняется**, если существуют связи на этом primitive.
- Параллельные и совпадающие оболочки нельзя объединять автоматически; требуется явное подтверждение. Совпадение координат само по себе **не доказывает** логическую связь, а unsupported skin/morph data отвергается.
- Нет UV unwrap/paint, полноценной редактируемой половинно-рёберной модели, геометрического Region Extrude сквозь seam и production migration. Требуются performance QA, наглядная подсветка всех совпадающих UV-seam пар, проверки на настоящем Huawei и Android APK.
- Chromium SwiftShader — программный WebGL2; **не** измерение Huawei Pura 80 Ultra. `main` не изменена. PR черновой, без слияния до разрешения владельца.
