# MARK Modeling API v0.4 — техническое описание

**Статус:** экспериментальный технологический прототип, не утверждённая 3D-модель MARK Cosmic. API предназначен для автоматической сборки GLB через GitHub Actions, без мыши и без платного GPU. Реализация: \`src/modeling-api.js\`, \`src/production-geometry.js\`. Схема: \`schemas/recipe-v0.4.schema.json\`.

## 1. Минимальный воспроизводимый запуск

\`\`\`bash
npm install --no-audit --no-fund
npm run test:modeling
npm run character:build -- --recipe recipes/stylized-face-demo.json
npm run character:build -- --recipe recipes/stylized-face-nose-variant.json
\`\`\`

CLI сохраняет \`dist/character/<project.id>/<project.id>.glb\`, \`recipe.json\`, \`report.json\` и \`checkpoint-*.glb\`. В отчёте есть SHA-256 рецепта и GLB, количество meshes/triangles/materials, выполненные команды, ошибки, предупреждения, диагностика головы. Запуск того же JSON с теми же исходными байтами должен создавать **побитно идентичный** GLB; проверяется тестом.

Если указан \`project.base="provided-glb"\`, необходимо передать \`--input path/to/your.glb\`. Внешний URL запрещён; основание должно быть самодостаточным GLB с редактируемой полигональной головой. Встроенное \`practice-head\` — демонстрационная голова, **не MARK Cosmic**.

## 2. JSON-схема

\`\`\`json
{
  "schema": "mark-modeling/0.4",
  "project": {"id": "my-stylized-head", "base": "practice-head"},
  "commands": [
    {"operation":"face.modify","target":"nose",
     "parameters":{"width":0.42,"length":0.65,"bridgeHeight":0.63}},
    {"operation":"feature.build","target":"eyes",
     "parameters":{"spacing":0.48,"size":0.66}},
    {"operation":"feature.build","target":"eyelids",
     "parameters":{"spacing":0.48,"size":0.66,"thickness":0.50}},
    {"operation":"feature.build","target":"lips",
     "parameters":{"width":0.56,"fullness":0.60,"smile":0.52}},
    {"operation":"feature.build","target":"ears",
     "parameters":{"width":0.55,"height":0.55}},
    {"operation":"feature.build","target":"hair",
     "parameters":{"length":0.58,"volume":0.52,"strands":0.64}},
    {"operation":"mesh.inspect"},
    {"operation":"checkpoint.save","target":"first-version"}
  ]
}
\`\`\`

Значения названных художественных параметров ограничены интервалом **0..1**. Это не физические метры или вероятность сходства. Внутри API параметры интерполируются в авторские диапазоны геометрии. Лицо направлено в локальное **+Z**, вверх **+Y**; базовая голова всё ещё непрерывная сетка из v0.3.

### 3. Доступные команды

| Operation | Target | Эффект |
|---|---|---|
| \`face.modify\` | \`head\`, \`nose\`, \`cheeks\`, \`chin\`, \`eyes\`, \`mouth\`, \`ears\` | Меняет координаты настоящего основного полигонального меша головы (на базе Face Studio) |
| \`feature.build\` | \`eyes\`, \`eyelids\`, \`eyebrows\`, \`lips\`, \`ears\`, \`hair\`, \`nostrils\` | Строит независимые контурные/объёмные меши с UV, NORMAL, индексами, материалами |
| \`geometry.loft\` | Имя объекта | Строит Mesh из 2–256 сечений по 3–512 XYZ точек. \`parameters.sections\` — массив секций |
| \`geometry.sweep\` | Имя объекта | Строит объёмную ленту/профиль вдоль \`parameters.path\` из XYZ точек, \`radius\`, \`depth\` |
| \`mesh.topology\` | Основная голова | Безопасный \`type\`: \`subdivide\`, \`inset\`, \`extrude\` и пр., \`faceIndex\`, \`amount\`, \`ratio\` |
| \`mesh.sculpt\` | Основная голова | \`point\`, \`radius\`, \`strength\`, \`mode\`, \`symmetry\`, \`falloff\`; реальная деформация с GLB-экспортом |
| \`object.transform\` | Номер узла | Вызов безопасных операций v0.3 \`type\`, \`nodeIndex\`, \`vector\` / \`rotation\` / \`preset\` |
| \`mesh.inspect\` | Основная голова | Диагностика из \`topology.js\`, не изменяет модель |
| \`checkpoint.save\` | Имя точки | Сохраняет отдельный snapshot GLB |

Ошибочные команды по умолчанию останавливают сборку и сообщают номер шага. Если у команды установлено \`"onError":"skip"\`, она **не применяет** изменение и записывает предупреждение. Важно: \`skip\` использовать только для необязательных художественных операций; не скрывать ошибки в контрольных тестах.

**Ограничения API:** \`feature.build\` в этой версии добавляет компоненты, а не удаляет старые. Для изменения параметров существующего лица рекомендуется **редактировать JSON и полностью пересобирать** проект с исходной базы — это детерминированно и сохраняет остальную геометрию. \`face.modify\` изменяет базовую поверхность, а независимые компоненты параметризуются через собственные \`feature.build\`; их числа следует согласовать вручную в рецепте. Полной системы геометрических ограничений для предотвращения пересечений ещё нет.

## 4. Как другой ChatGPT работает через GitHub

1. Подключить GitHub с разрешением редактировать **только согласованную ветку разработки** (не \`main\`).
2. Считать \`docs/MODELING-API-v0.4.md\`, \`schemas/recipe-v0.4.schema.json\`, исходный рецепт из \`recipes/\`.
3. Скопировать рецепт в \`recipes/<new-name>.json\`; задать уникальный \`project.id\` и изменить параметры. Не добавлять приватные художественные изображения в GitHub.
4. Сохранить JSON коммитом в ветке \`develop/character-production-v0.4\`. Workflow \`modeling-v04.yml\` запускается **на push** в эту ветку и собирает все \`recipes/*.json\`.
5. Открыть успешный GitHub Actions run. Скачать артефакт \`mark-3d-studio-v0.4-modeling-api-glb-reports\`, открыть \`report.json\`, GLB, семь PNG ракурсов, wireframe и \`camera-report.json\`.
6. Оценить геометрию и параметры, сравнить рендеры предыдущего и следующего JSON; повторить цикл новым коммитом. **Ни один коммит не сливать в \`main\` без явного одобрения.**
7. На Huawei открыть автономный HTML из артефакта этого же CI-запуска; сверить \`<meta name="mark-source-commit">\` с GitHub SHA запуска. Это исправляет проблему, когда HTML был собран не из текущих исходников.

Внешняя автоматическая художественная оценка сходства с MARK Cosmic **не реализована**. ChatGPT может просмотреть PNG и предложить обновлённый рецепт, но не должен сообщать о готовом сходстве без визуального сравнения с утверждёнными референсами.

## 5. Рендеры и ограничения

Скрипт \`scripts/render-character.mjs\` после сборки GLB загружает **экспортированный файл** через Three.js GLTFLoader в настоящий Chromium/WebGL2. Камеры фиксированы: front, left, right, threequarter-left, threequarter-right, face-close, wireframe. Фиксированы ортографическая проекция, освещение, масштаб и фон; записываются позиции камер. Разрешение и настройки CI — не измерение производительности на Huawei. Используется программный рендерер SwiftShader, без NVIDIA RTX.

Инструменты v0.4 **не дают** производства фотограмметрически точного/узнаваемого лица из картинки, реалистичной ротовой полости и подвижных лицевых колец, ручной ретопологии уровня Blender, симуляции волос/ткани или автоматического устранения пересечений всех независимых деталей. Лицо всё ещё начинается с общей тренировочной головы v0.3; дополнительные объёмы строятся по специализированным кривым и сечениям, поэтому изображение стало более детальным, но **до утверждённого MARK Cosmic потребуется отдельная художественная итерация** и контроль качества в шести ракурсах.

## 6. Источники и приватность

Референсы MARK Cosmic приложены к чату, но **не доступны автоматически GitHub Actions** и не должны публиковаться по умолчанию. Конфигурация landmark/camera должна храниться отдельно от GLB; текущий API предупреждает при отсутствии изображений, а автоматическое landmark-fitting пока не выполняется. Лицензии: ядро проекта MIT, Three.js MIT, esbuild MIT, Playwright Apache-2.0. CI в GitHub требует доступного бесплатного лимита Actions и может расходовать минуты приватного репозитория.
